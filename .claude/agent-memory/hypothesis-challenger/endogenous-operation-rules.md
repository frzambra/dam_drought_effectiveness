description: Apparent storage-depletion thresholds in dammed basins are likely operating rules, not emergent physical rectification

Reservoir releases follow human operating policy (rule curves, irrigation allocation priorities, minimum-flow/dead-storage constraints). A detected "critical storage fraction" threshold at which releases collapse toward inflow is the EXPECTED signature of an operating rule, not evidence of an emergent nonlinear rectifier mechanism.

**Why:** TAR / Markov-switching models will happily locate a threshold that coincides with dead storage or an allocation rule curve. Finding the threshold confirms the operating policy, not the proposed "suppressed-deficit backlog releases at once" mechanism. This is a confirmation-bias trap specific to this project.

**How to apply:** Before crediting any nonlinear "rectification" story, get reservoir operating information / rule curves (CLAUDE.md lists this as an expected data source) and test whether detected thresholds simply equal documented operating constraints. If they do, the mechanism reduces to "operators ration water in droughts" — true but not novel. Related: [[reservoir-drought-alternatives]].
